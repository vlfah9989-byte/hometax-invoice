# 세금계산서 자동 발급 (비공개)

- `거래처입력.py` : 입력·발급·점검·설정 화면 → `세금계산서.exe`
- `홈택스열기.py` : 홈택스 자동 발급·이미지 저장 → `홈택스발급.exe`
- `업데이트.py` : 켤 때 최신 릴리스를 받아 exe 교체

## 새 버전 배포
1. 코드 수정 후 커밋·푸시
2. `git tag v1.0.1 && git push origin v1.0.1`
3. Actions 가 exe 를 만들어 릴리스에 올림 → 아버지 PC 가 다음에 켤 때 자동 업데이트

## 저장소에 절대 올리지 않는 것
설정.json(아이디·비번·개인정보·토큰), 보안카드.txt, 발급기록.txt, 거래처기록\, 장부 이미지 —
전부 프로그램 폴더(이 폴더 바깥)에만 있고 `.gitignore` 로도 막혀 있음.
